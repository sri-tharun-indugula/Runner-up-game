# Tharun Infinity Runner

Arcade endless runner built with **TypeScript**, **Phaser 3**, and **Vite**.

## Play

```bash
npm.cmd install
npm.cmd run dev
```

Open http://localhost:8080/

## Scripts

| Command | Description |
|---------|-------------|
| `npm.cmd run dev` | Local development server |
| `npm.cmd run build` | Typecheck + production build |
| `npm.cmd run preview` | Preview production build |

## Controls

- **Jump:** Space / ↑ / click / touch JUMP
- **Pause:** P / Esc / touch Pause
- **FPS monitor:** F (or Settings)

## Features

Milestones 1–20: scrolling world, player, obstacles, collectibles, score, difficulty, audio, UI, power-ups, particles, animations, mobile, performance, save/unlocks, polish, final testing checklist (`TESTING.md`).
